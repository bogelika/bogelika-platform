# Как мы работаем (для Анастасии)

Ты не обязана быть программистом. Схема такая:

| Кто | Что делает |
|-----|------------|
| **Cursor (я)** | Пишу и меняю код и документацию в проекте, объясняю простыми словами |
| **Ты на компьютере** | Публикуешь изменения на **GitHub** (одна-две команды или GitHub Desktop) |
| **Ты на сервере** | Подтягиваешь код с GitHub и перезапускаешь бота (команда, которую мы зафиксируем ниже) |

Секреты (токен Telegram, пароли) **никогда** не кладём в GitHub — только в файл `.env` на сервере.

---

## Что сейчас лежит в репозитории `bogelika-platform`

На GitHub в этом репозитории сейчас в основном:

- папка **`docs/`** — описание проекта;
- папка **`workflows/`** — старые **экспорты из n8n** (архив / референс, не обязательно то, что крутится у вас сейчас);
- папка **`code/`** — небольшие JS-модули (логика для бота).

**Отдельного готового приложения бота** (с `package.json`, папкой `bot/` и т.д.) в репозитории пока **нет**, если только оно не живёт в другом репозитории или только на сервере без выгрузки в GitHub.

Нам нужно один раз сверить: **где именно сейчас работает боевой бот** — тогда все следующие фичи (поиск, кабинет) делаем **там же**, в коде на GitHub + деплой на сервер.

## Шаг 1 — опубликовать на GitHub (после моих правок)

### Вариант А: GitHub Desktop (проще)

1. Открыть GitHub Desktop, выбрать репозиторий **bogelika-platform**.
2. Слева появятся изменённые файлы → внизу написать короткое описание → **Commit to …**.
3. Нажать **Push origin**.

### Вариант B: терминал на твоём Mac/PC

```bash
cd путь/к/bogelika-platform
git pull
git status
git add .
git commit -m "кратко: что изменили"
git push
```

(Если работаешь в ветке от Cursor — сначала `git checkout имя-ветки`, как напишу в сообщении.)

## Шаг 2 — обновить на сервере

**Здесь нужна твоя реальная команда.** Обычно это что-то вроде:

```bash
ssh user@ваш-сервер
cd /путь/к/проекту
git pull
# дальше — перезапуск, зависит от того, как у вас настроено:
npm install
pm2 restart bogelika-bot
# или: docker compose up -d --build
# или: systemctl restart bogelika-bot
```

Напиши мне (или скинь скрин/текст), **что ты сейчас вводишь на сервере после обновления** — я впишу точные строки в этот файл, чтобы каждый раз копировать одно и то же.

## Как формулировать задачи мне

Хорошо работает так:

- «Нужно, чтобы в одном боте были отчёты и поиск»
- «Хочу видеть список мастеров в кабинете»
- «Вот username второго бота / вот что сейчас на сервере в папке …»

Я сначала коротко скажу **что поменяю**, потом сделаю код, потом дам **готовые команды** для GitHub и сервера.
