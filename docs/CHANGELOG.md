## Telegram-бот

Реализовано:

- создание нового отчёта;
- открытие сессии мастера;
- получение фотографий;
- получение текста отчёта;
- сборка Telegram-альбомов;
- проверка текста отчёта;
- возможность дополнить неполный отчёт;
- возможность сохранить отчёт неполным, если мастер не может уточнить данные;
- закрытие сессии после завершения отчёта;
- сообщение мастеру об успешном сохранении отчёта.
