# DATABASE

## tg_reports_pilot

### Назначение
Основная таблица, в которой хранится полностью собранный отчёт мастера после завершения проверки.

### Что хранит
- полный текст отчёта
- информацию о студии
- мастере
- клиенте
- статусе отчёта
- ссылки на фотографии
- report_key
- даты создания и обновления

### Основные поля
- id
- report_key
- studio
- master
- client
- report_text
- photo_links
- status
- created_at
- updated_at

### Возможные статусы
- pending — отчёт ещё собирается
- incomplete — ожидается дополнение
- completed — отчёт полностью заполнен
- cancelled — сессия завершена без сохранения (если появится)

### Кто использует
- Telegram Bot
- n8n Workflow «Приём отчётов мастеров»
- Google Sheets
