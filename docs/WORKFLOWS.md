# Workflows

## TG — Приём отчётов мастеров — PILOT

Назначение

Основной workflow проекта.

Функции:

- запуск нового отчёта
- создание сессии
- получение фотографий
- получение текста
- сохранение частей отчёта
- завершение отчёта
- повторная проверка недостающих смысловых блоков после дополнения

Использует:

- tg_report_sessions_pilot
- tg_report_parts_pilot

---

## TG — Сборка альбомов — PILOT

Назначение

Обработка завершённых Telegram-альбомов.

Функции:

- ожидание окончания отправки фотографий
- объединение альбома
- проверка текста
- проверка студии, мастера, клиента, описаний до/после и длительности
- сохранение отчёта
- экспорт в Google Sheets

Использует:

- tg_report_parts_pilot
- tg_reports_pilot

---

## TG — БОГЕЛИКА мастера — PILOT (планируется)

Единый Telegram-бот: текущий «Приём отчётов» + поиск + кабинет.

Функции (новые):

- проверка доступа по `staff_directory_pilot`
- «🔍 Мои отчёты» — subflow поиска в `tg_reports_pilot`
- «👤 Кабинет» — открытие Mini App
- режим сессии `mode: search`

Спецификация: [UNIFIED_BOT_AND_CABINET.md](./UNIFIED_BOT_AND_CABINET.md)

---

## Cabinet API — PILOT (планируется)

Webhook для Telegram Mini App (и позже веб-кабинета):

- `me` — профиль и роль
- `my-reports` — список с фильтрами
- `staff-list` / `staff-update-status` — для admin/manager
