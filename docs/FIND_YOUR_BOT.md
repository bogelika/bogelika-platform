# Где живёт бот «для мастеров» — как показать это Cursor

Cursor в облаке **не видит** папки на твоём компьютере, пока ты их явно не откроешь или не прикрепишь файлы.

## Шаг 1 — найти папку на компьютере

1. Открой **Проводник** (Windows) или **Finder** (Mac).
2. В поиске набери: `бот для мастеров` или `bogelika`.
3. Зайди в папку и посмотри, есть ли там файлы вроде:
   - `README.md`
   - `package.json`
   - `docker-compose.yml`
   - `.env.example`
   - папки `src`, `bot`, `app`

Запиши **полный путь** к папке (на Mac: правый клик по папке → «Скопировать … как pathname»).

---

## Шаг 2 — один из трёх способов показать Cursor

### Способ А (лучший): открыть эту папку в Cursor

1. Cursor → **File → Open Folder…**
2. Выбери папку **«бот для мастеров»**.
3. Напиши агенту: «Я открыла папку бота, посмотри проект».

Тогда агент увидит весь код, как на GitHub.

### Способ Б: прикрепить 2–3 файла в чат

Перетащи в сообщение Cursor:

- `README.md` (если есть)
- `package.json` (если есть)
- любой файл с названием `deploy`, `Dockerfile`, `ecosystem.config.js`

Без `.env` — там секреты, его не прикрепляй.

### Способ C: GitHub Desktop

1. Открой GitHub Desktop.
2. Посмотри список репозиториев слева.
3. Если **«бот для мастеров»** привязан к репозиторию — напиши **точное имя** (например `bogelika/bogelika-platform` или другое).

---

## Как понять, «тот ли это» проект

| Признак | Значит |
|--------|--------|
| Внутри только `docs` и `workflows` | Это скорее **bogelika-platform** (документация + архив n8n) |
| Есть `package.json` + папка с кодом | Это **приложение бота** — его и нужно развивать |
| GitHub Desktop показывает другой remote, не bogelika-platform | Код бота может быть в **другом** репозитории |

---

## Что написать агенту одним сообщением

Скопируй и заполни:

```text
Путь к папке на компьютере: …
GitHub Desktop — имя репозитория: …
В папке есть package.json: да / нет
Username бота в Telegram: @…
```

После этого можно прописать **точные команды** для публикации в [HOW_WE_WORK.md](./HOW_WE_WORK.md).
