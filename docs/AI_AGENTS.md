# AI Agents

## Назначение

В этом документе описаны все AI-агенты платформы BOGELIKA, их задачи и текущий статус.

---

# Agent 1 — Проверка текста отчёта

Статус: Планируется

Назначение:

- понимать свободный текст мастера
- извлекать обязательные поля
- понимать сокращения ("ЖП", "70 минут", "Дарья С.")
- определять, каких данных не хватает
- формировать структурированный отчёт

---

# Agent 2 — Проверка фотографий

Статус: Планируется

Назначение:

- определить, все ли обязательные фотографии приложены
- проверить качество фотографий
- определить наличие затёков
- определить наличие отслоек
- проверить качество зоны кутикулы
- определить смазанные фотографии
- проверить наличие фотографии цвета

---

# Agent 3 — Анализ качества работы мастера

Статус: Планируется

Назначение:

На основании большого количества отчётов выявлять:

- повторяющиеся ошибки
- сильные стороны мастера
- рекомендации по обучению

---

# Agent 4 — Помощник администратора

Статус: Планируется

Назначение:

- анализировать записи на сегодня
- формировать рекомендации администраторам
- предлагать допродажи
- напоминать о важных клиентах

---

# Agent 5 — Помощник управляющего

Статус: Планируется

Назначение:

- анализировать все отчёты мастеров
- искать системные проблемы
- показывать динамику качества
- уведомлять о повторяющихся ошибках

---

# Agent 6 — Помощник собственника

Статус: Планируется

Назначение:

- анализировать работу всей сети
- строить отчёты
- выявлять точки роста
- помогать принимать управленческие решения

---

# Общий принцип

Все AI работают как помощники.

Окончательное решение всегда остаётся за человеком.
