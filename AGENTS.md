# BOGELIKA Platform

Ты работаешь над системой автоматизации сети студий красоты BOGELIKA.

Перед выполнением любой задачи:

1. Прочитай README.md
2. Прочитай всю документацию в папке docs/
3. Изучи существующие workflow перед изменениями.
4. Не удаляй существующую логику без необходимости.
5. Предлагай минимальные изменения.
6. После добавления новой функции обновляй:
   - CHANGELOG.md
   - FEATURES.md
   - ROADMAP.md (если меняется план проекта)
7. Не сохраняй секреты (API-ключи, токены, пароли) в репозитории.
8. Если изменение затрагивает архитектуру, обнови ARCHITECTURE.md.
9. Если появляется новая таблица Data Tables, обнови DATABASE.md.
10. Если появляется новый workflow, обнови WORKFLOWS.md.

## Структура проекта

- docs/ — документация
- workflows/ — экспортированные workflow n8n
- prompts/ — промпты для AI
- code/ — JavaScript и вспомогательный код
- assets/ — изображения, схемы и ресурсы
- examples/ — примеры данных

## Главный принцип

Сначала сохранность данных, потом интеграции.

Никогда не предлагай изменения, которые могут привести к потере данных пользователей.
