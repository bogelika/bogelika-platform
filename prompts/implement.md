# Реализация новой функции

Следуй правилам из prompts/system.md

Задача пользователя:

[ВСТАВИТЬ ОПИСАНИЕ ФУНКЦИИ]

Сначала изучи связанные файлы и подготовь план

До получения разрешения пользователя ничего не изменяй

В плане укажи:

1. Как функция должна работать
2. Какие файлы и workflow затрагиваются
3. Какие данные добавляются или изменяются
4. Как избежать дублей и потери данных
5. Какие сценарии ошибок нужно обработать
6. Как протестировать функцию
7. Как откатить изменения

После одобрения реализуй только согласованный вариант

Не создавай коммит и не выполняй push без отдельного разрешения
