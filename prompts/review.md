# Проверка изменений

Следуй правилам из prompts/system.md

Проведи review текущих изменений или указанного файла

Ничего не изменяй

Проверь:

1. Не потеряются ли данные
2. Не появятся ли дубли по report_key
3. Не нарушена ли логика сессий
4. Совпадают ли названия полей с Data Tables
5. Нет ли служебных полей, которые случайно записываются в таблицы
6. Корректно ли обработаны пустые значения
7. Есть ли повторная попытка после временного сбоя
8. Не содержит ли проект секреты
9. Обновлена ли связанная документация
10. Можно ли безопасно импортировать workflow обратно в n8n

Раздели результат на:

- критические ошибки
- важные замечания
- необязательные улучшения
- итоговый вердикт
