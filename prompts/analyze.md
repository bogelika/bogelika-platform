# Анализ проекта без изменений

Следуй правилам из prompts/system.md

Изучи репозиторий и используй только безопасные команды чтения

Ничего не изменяй, не создавай файлы и не выполняй Git-команды записи

Подготовь отчёт:

1. Как сейчас устроена система
2. Какие workflow существуют и как они связаны
3. Какие Data Tables и внешние сервисы используются
4. Что уже реализовано
5. Где документация расходится с фактическими workflow
6. Какие ошибки или риски видны
7. Какие три задачи имеют наивысший приоритет
8. Что нужно проверить вручную в n8n

Для каждого риска укажи:

- серьёзность
- возможные последствия
- минимальный вариант исправления
