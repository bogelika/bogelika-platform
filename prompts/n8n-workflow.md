# Работа с workflow n8n

Следуй правилам из prompts/system.md

При анализе JSON workflow учитывай:

- JSON является экспортом из n8n, а не обычным приложением
- credentials могут отсутствовать или быть обезличены
- изменение JSON не применяет изменения автоматически к работающему n8n
- после правок workflow потребуется вручную импортировать или обновить в n8n
- нельзя ломать существующие connections между нодами
- нельзя менять ID нод без необходимости
- нельзя удалять неизвестные настройки только потому, что они выглядят лишними
- Code-ноды должны возвращать структуру, совместимую со следующими нодами
- названия колонок должны точно совпадать с Data Tables и Google Sheets
- ветки true и false нужно проверять отдельно
- Schedule Trigger и Telegram Trigger должны сохранять текущую логику запуска

Перед изменениями подготовь:

1. Список затрагиваемых нод
2. Текущую цепочку прохождения данных
3. Новую цепочку
4. Изменяемые поля входа и выхода
5. Возможные ошибки
6. Пошаговый план ручного импорта и проверки в n8n

Не меняй JSON до явного разрешения пользователя
