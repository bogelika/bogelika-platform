# BOGELIKA Platform

AI-платформа автоматизации сети студий красоты «БОГЕЛИКА».

## Что уже реализовано

- Прием отчетов мастеров через Telegram
- Проверка текста отчета
- Дозаполнение отчета
- Сохранение фотографий
- Выгрузка в Google Sheets

## Структура проекта

/workflows — экспортированные workflow n8n

/docs — документация проекта

/code — JavaScript-код из Code-нод

/examples — примеры отчетов

/assets — схемы, изображения и материалы
