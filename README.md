# BOGELIKA Platform

AI-платформа автоматизации сети студий красоты «БОГЕЛИКА».

## Что уже реализовано

- Прием отчетов мастеров через Telegram
- Проверка текста отчета
- Дозаполнение отчета
- Сохранение фотографий
- Выгрузка в Google Sheets

## В работе (проектирование)

- Единый бот: сдача отчётов + поиск «Мои отчёты» + личный кабинет
- Реестр сотрудников и управление доступом

См. [docs/UNIFIED_BOT_AND_CABINET.md](docs/UNIFIED_BOT_AND_CABINET.md)
